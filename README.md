# 溢彩画 · ColorfulPainting

《鸣潮》溢彩画的网页复刻。

[在线体验](https://overflowing-palette.vercel.app/)

## 实现流程

1. **整理关卡与素材**：从原版配置中整理出 65 份关卡，保留棋盘、基础步数、目标色、可用颜色和奖励规则；将图片、颜料纹理、字体与音效整理为网页可用的资源。

2. **初始化游戏**：入口创建游戏会话，读入关卡数据，并行加载渲染资源和音频。首次绘制完成后退出加载界面，显示棋盘、步数、选关列表和颜料栏。

3. **计算连通染色**：玩家先选颜料，再点击色块。程序从点击位置出发，按上下左右查找同色连通区域，将整片区域染成所选颜色。一次有效染色消耗一步，同色点击不扣步。灰格不参与染色，也不能被穿过；每一步都可以更换起点。

4. **呈现染色动画**：查找连通区域时同时记录传播层数和方向，再按传播距离安排各格动画。Three.js 根据原版材质公式、纹理和动画曲线绘制色块变化，Canvas 2D 合成背景、边框与颜料栏，独立 SVG 显示标题、步数和状态文字。

5. **推进游戏与切换关卡**：游戏会话统一管理绘制、胜负、重置和奖励步数；主循环逐帧推进动画并触发对应音效。动画结束后检查所有可染色格是否达到目标色，通关后自动进入下一关。选关和自动切关使用棋盘及边框的局部溶解过渡，界面控件保持稳定。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

## 构建与离线运行

```sh
npm run build
```

双击生成的 `dist/index.html` 即可离线游玩，也可通过 `npm run preview` 预览构建结果。
