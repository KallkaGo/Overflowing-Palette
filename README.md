# 溢彩画 · ColorfulPainting

《鸣潮》溢彩画的网页复刻。

[在线体验](https://overflowing-palette.vercel.app/)

## 实现流程

核心是四邻域洪水填充（Flood Fill），使用广度优先搜索（BFS）确定本次染色的连通区域。

1. 读取点击格的原色。如果它是灰格，或原色与所选颜料相同，则忽略本次操作，不扣步。

2. 将起点加入队列并标记已访问。依次取出队首格，检查上下左右的邻格，将与起点原色相同且未访问的格子标记并入队，直到队列处理完毕。灰格不会进入连通区域。

3. 将收集到的全部格子统一替换为所选颜色，剩余步数减一。

4. 染色动画结束后，遍历所有非灰格：全部为目标色则通关，否则在剩余步数为零时判定失败。

设棋盘共有 N 个格子，单次染色计算的最坏时间和额外空间复杂度均为 O(N)。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

## 构建与离线运行

```sh
npm run build
```

双击生成的 `dist/index.html` 即可离线游玩，也可通过 `npm run preview` 预览构建结果。
